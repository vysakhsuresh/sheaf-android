
## Working rules for this repository

- Sheaf is the Android app. Foolscap (`vysakhsuresh/foolscap`) is the web version and is a
  reference only: read it for how a tool should behave, never edit it from a Sheaf session,
  and never edit `layerlink-android` or any other repository from here either.
- All work lands on `main` and is pushed; there are no long-lived branches.
- Sheaf aims to be a step ahead of Foolscap, not level with it: every Foolscap tool exists
  here, and the phone-only ones (scan, read aloud, Devanagari OCR, system fonts for Indian
  scripts) go beyond it.
